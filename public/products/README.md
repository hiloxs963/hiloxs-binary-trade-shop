# Product image assets

HILOXS product photography belongs under one directory per product slug:

```text
public/products/<product-slug>/primary.webp
public/products/<product-slug>/detail-01.webp
```

Only add photographs that HILOXS owns, has licensed, or has received with documented permission.
Record the source and permission outside the public asset directory. Prefer WebP or AVIF, keep the
original aspect ratio, and use descriptive alt text in the product data. Until an approved image is
available, the storefront deliberately shows a "Licensed photo pending" state.
